Showcase web and gpu software development resources using server and serverless infrastructures.

## Website

https://www.blockbreak.ca

Resources:
 - AWS CloudFront
 - AWS Route53
 - AWS S3
 - React 19.2

## Client

Interactive React app.  Uses WebSockets to connect to the backend servers.  Can connect to either server or serverless infrastructer.

Resources:
 - AWS Route53
 - AWS CloudFront
 - AWS S3
 - React 19.2
 - Vite
 - Vitest
 - Testing Library

## Server

Resources:
 - Docker compose
 - Spring framework
 - GraphQL
 - MongoDB
 - MySQL
 - PostgreSQL

## Serverless

Resources:
- AWS Lambdas
- AWS DynamodDB
- AWS API Gateway
